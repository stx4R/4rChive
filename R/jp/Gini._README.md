# Gini.

<p align="center"><img src="../assets/kr/Gini/cover.png" alt="Gini. 代表画像" width="100%"></p>

> 性別を除いて学習させた「ブラインド」な所得分類器が性別の格差をそのまま再現していないかを、微積分で監査した2段階の探究。定積分で差別を測る指標を作り、その指標を微分して、精度と公正性をあわせて考慮した判定の閾値を解析的に求めた

## 1. プロジェクト概要 (Overview)

| 項目 | 内容 |
|---|---|
| プロジェクト名 | Gini.（実技評価② 「ジニ係数が隠した差別」 → 実技評価③ 「公正性の積分監査器」） |
| 一行要約 | ジニ係数は集団間の平均の格差を捉えられないことを示し、2本のローレンツ曲線の間の面積`D`を提案した。続いて`J(t) = Acc(t) − λD(t)`の1階条件から最適な閾値`t*`を導き、実データのグリッドサーチと精度の差1.9%以内で一致させた |
| 期間 | 2026.06（2年生「微積分学」の実技評価（遂行評価）②・③、数学的分析の要約書） |
| 参加人数 | 個人での探究 |
| 本人の役割 | テーマ設計、数式の導出、Pythonの分析パイプライン、結果の解釈、レポート・ポスターの作成 |
| 貢献度 | 100% |

ワークシートで定積分を使ってローレンツ曲線とジニ係数を求めているうちに、不平等を1つの数に圧縮するこの道具を人工知能にも使えるのではないかと気になった。**AIモデルの公正性も、こうやって測れるだろうか？ その測定は信頼できるだろうか？**

融資・採用・福祉の選別にAIによる自動審査が広がるにつれ、「デジタル弱者」の問題が大きくなっている。アルゴリズムが特定の集団を構造的に不利に判定してしまう問題である。よくある対策は、性別のような保護変数を学習から外すことだ。しかし、ほかの変数が性別と相関していれば、性別の情報はその変数を経由して間接的に入り込む。だからこそ、デプロイ前にモデルの出力を直接調べる事後監査のツールが必要だと考えた。

| 仮説 | 内容 | 検証 |
|---|---|---|
| 1. 代理変数 | 保護属性を外しても、モデルは現実の格差に近い結果を出す | 集団ごとのモデルの平均スコア vs 現実の基準率 |
| 2. 平均不変性 | 単一のジニ係数は集団間の平均の格差に鈍感で、差別的なモデルを公正だと誤判定する | 統合ジニ係数の反応 |
| 3. 積分格差指数 | 2本のローレンツ曲線の間の面積`D`は、ジニ係数が見落とす格差を捉え、閉形式と数値積分が一致する | 閉形式 vs 台形公式による積分 |
| 4. 微分による最適化 | `J′(t*) = 0`の解析解は、グリッドサーチの最適点と同じ性能を出す | 2つの`t*`での精度の差 |
| 5. trade-off | 閾値だけで完全な公正に近づけると、`t*`が上限に張り付いて分類器が役に立たなくなる | λのスイープ |

## 3. 主な機能と担当業務 (Key Features & Contributions)

### 設定

- モデルが各人に与えた高所得スコア`s`を、分配される資源とみなす。所得の代わりにスコアを分配の対象に置けば、所得の不平等を測る指標をそのままAIの監査に持ち込める。
- 性別で集団を分ける：A（男性、人口比0.680、基準率0.315） · B（女性、0.320、0.108）。この**基準率の格差 +0.207**が、後であらゆる格差の根源であることが明らかになる。

### Phase 1 — 定積分で測る

```
G = 2 ∫₀¹ ( x − L(x) ) dx,    L(x) = xⁿ  ⇒  G = (n − 1)/(n + 1),   n = (1 + G)/(1 − G)
D = ∫₀¹ | L_M(x) − L_F(x) | dx = | 1/(n_M + 1) − 1/(n_F + 1) |
```

集団ごとのスコアを並べ替えて累積し、台形公式による積分で`G`を求め、そこから`n`を逆算した。曲線の間の面積という幾何的な定義が`xⁿ`モデルでは閉形式に落ちるので、数値積分と解析解で互いを検証できる。

### Phase 2 — 微分で直す

```
SR_g(t) = ∫ₜ¹ f_g(s) ds,   Δ(t) = SR_A(t) − SR_B(t),   D(t) = Δ(t)²
Acc(t)  = Σ_g π_g [ p_g ∫ₜ¹ f_{g,1} ds + (1 − p_g) ∫₀ᵗ f_{g,0} ds ]

J′(t) = Acc′(t) + 2λ Δ(t) [ f_A(t) − f_B(t) ] = 0
```

- 選択率・精度をすべてスコア密度の定積分として定義し、微積分学の基本定理で微分すると、**境界`t`での密度の値だけが残る。**`D′`には連鎖律と基本定理が重ねて使われる。
- λ = 0のとき、1階条件は古典的な**ベイズ閾値**に帰着するので、これでモデルを点検できる。
- ロジットが正規分布に従う（ロジット正規）と仮定すると、選択率は`Φ((μ − logit t)/σ)`という閉形式になる。このとき、クラス条件付き密度が集団によらなければ**`D ∝ (p_A − p_B)²`**となり、格差の根源が基準率の差であることが式の上で見える。

| 集団・クラス | μ | σ |
|---|:---:|:---:|
| A1（男性・陽性） | +0.78 | 2.39 |
| A0（男性・陰性） | −2.63 | 2.12 |
| B1（女性・陽性） | +0.47 | 2.39 |
| B0（女性・陰性） | −3.58 | 1.74 |

### 分析パイプライン

ブラインドLRの学習 → 集団・クラスごとのロジット正規分布の当てはめ → `J′(t*) = 0`の解析解（`brentq`） → 実データでのグリッドサーチ → λのスイープ・可視化。1本のスクリプト（206行）で全工程を回し、結果を`results.json`に残す。

### 主な業務

- ジニ係数の平均不変性の論証と、格差指数`D`の設計
- 選択率・精度の積分による定義、FTC・連鎖律を使った1階条件の導出、ロジット正規による具体化と系`D ∝ (p_A − p_B)²`
- Pythonの分析パイプラインと、解析解–グリッドサーチのクロス検証
- レポート（実技評価②は3ページ、実技評価③は8ページ）と数学的分析の要約ポスターの作成

### 定性的成果

- **「センシティブな変数を外せば公正になる」という通念を数値で反論した。** 性別を外したモデルが女性11.5% · 男性30.1%と、現実（10.9% · 30.4%）をほぼそのまま描き出した。
- モデルが生んだ格差は現実と同程度の大きさだったのに、よく使われる指標（統合ジニ係数）では見えなかった。
- 「積分で測り、微分で直す」という一言で2つの実技評価をつないだ。前の段階では標準的な指標が差別を見落とすことを示し、後の段階では、それならどこで線を引くべきかに答えた。
- 政策判断用の表も作った。λを組織の政策パラメータとして置けば、公正性をどれだけ得るために精度をどれだけ手放すかを、フロンティアの表から選べる。

### 確認された限界

- **ブラインドモデルに`relationship`変数が含まれている。** この変数の値（Husband · Wife）は、性別をほぼそのまま表してしまう。仮説1で言う代理変数を通じた間接的な流入は、婚姻状況や労働時間のような弱い代理変数よりも、この変数の影響のほうが大きい可能性がある。この変数を外して再実行してみる必要がある。
- 解析解とグリッドサーチの`t*`の位置のずれの一部は、ロジット正規という仮定の近似誤差から来ている。
- **閾値の調整だけでは、基準率の格差には手が届かない。** 前処理（再重み付け）や、学習中の公正性制約を併用する必要がある。
- 公正性の基準は、選択率の格差（Demographic Parity）1つだけを最適化した。機会均等・均等化オッズと同時には満たせないという不可能性定理は扱っていない。
- 監査したのは性別だけで、人種・年齢との交差的な格差は扱っていない。
- 表1の数値はレポートに画像として入っているため、今回は元データと再照合できなかった。スクリプトは残っているが、データファイル（`adult.data`）がローカルにないので再実行していない。（要確認）

## 5. トラブルシューティング (Troubleshooting)

### ① ジニ係数では差別が見えなかった

**問題** 性別を外したモデルのスコアで統合ジニ係数を求めると、0.569という1つの数しか出なかった。この値からは、女性が男性よりはるかに低いスコアを受けているという事実を読み取れなかった。

**原因** ジニ係数は分布の集中度しか測らない。すべてのスコアを`c`倍しても`G`は変わらない（平均不変性）。ある集団のスコアを丸ごと半分に削っても、ジニ係数はそのままである。

**解決** 集団ごとにローレンツ曲線を別々に描き、2本の曲線の間の面積を新しい指標`D`と定義した。`L(x) = xⁿ`でモデル化すると`D`が閉形式に落ちるので、台形公式による数値積分と解析解で互いに検証できるようにした。

**結果** `D` = 0.064が閉形式と0.06の水準で一致した。ジニ係数0.569の裏に隠れていた平均の格差18.6%pを、`D`で浮かび上がらせた。

### ② 解析解とグリッドサーチの`t*`が食い違った

**問題** 解析解で求めた`t*`と、実データでのグリッドサーチの`t*`が、λが小さい区間でかなり離れていた。λ = 3では0.8407対0.7485だった。

**原因** ロジット正規という仮定の近似誤差もあるが、より大きな理由は、精度の目的関数が最適点の近くで平らなことにある。平らな山頂では、位置が違っても高さ（精度）はほとんど変わらない。

**解決** 検証の基準を変え、位置が同じかどうかではなく、その位置での性能が同じかどうかを見るようにした。2つの`t*`で測った精度を並べて比べ、λ = 0で1階条件がベイズ閾値に帰着するか（`Acc′(t*) ≈ 0`）もあわせて確認した。

**結果** すべてのλで精度の差は1.9%p以内に収まり、λ = 0では`Acc′(t*) ≈ 4.6 × 10⁻¹⁷`となった。導いた1階条件が正しいという根拠を、2つの方向から得た。

### ③ λをいくら大きくしても格差が0にならなかった

**問題** λを30、100に上げても`t*`は0.98で止まり、DP格差は0.018からそれ以上縮まらなかった。その間、精度だけが0.844から0.771に落ちた。

**原因** ロジット正規モデルでクラス条件付き密度が集団によらなければ、`D ∝ (p_A − p_B)²`となる。格差の根源はモデルではなく、基準率の格差（+0.207）にある。閾値をどこに置いても、この定数項は消えない。

**解決** 閾値の調整という後処理の限界を式で示し、結論に「完全な公正はタダではない」と明記した。前処理（再重み付け）と学習中の公正性制約を併用すべきだという今後の方向性を示した。

**結果** 閾値だけで完全な公正に近づけようとすると、分類器（`t*` = 0.98）がほぼ全員を不合格にしてしまうことを定量的に示した。

<details>
<summary><b>用語</b></summary>

- **平均不変性**：すべての値を`c`倍してもジニ係数が変わらない性質
- **代理変数**：保護属性との相関が高く、その情報を間接的に伝えてしまう変数
- **基準率**：集団の中での実際の陽性の割合
- **DP格差**：2集団の選択率の差。0なら人口統計的に同等（Demographic Parity）
- **微積分学の基本定理（FTC）**：積分の上端・下端を変数として微分すると、境界での被積分関数の値だけが残る
- **ロジット正規分布**：ロジット変換した値が正規分布に従う、`[0,1]`上の分布
- **ベイズ閾値**：精度を最大化する古典的な閾値。λ = 0のときの特殊解
- **精度–公正性フロンティア**：格差を縮めるほど精度が下がる関係を描いた曲線

</details>
